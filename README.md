# Web Traffic Analysis
A simple analysis of web traffic data flagged as suspicious.

## Dataset
[Cybersecurity Suspicious Web Threat Interactions on Kaggle](https://www.kaggle.com/datasets/jancsg/cybersecurity-suspicious-web-threat-interactions)

## Some Findings
- Most traffic is either very small (possible scanning) or very large
- US and Canada account for about 65% of all suspicious traffic
- Most activity occurs at 1 AM and during business hours (9-10 AM)
